# Telegram-бот лофт-студии «Луна»

Виртуальный менеджер по продажам в Telegram. Бот отвечает на вопросы о студии, помогает выбрать формат съёмки или аренды и мягко ведёт клиента к заявке. Текстовые ответы генерирует **GigaChat**, изображения — **ProxyAPI** (OpenAI-совместимый API).

## Что делает ассистент

Бот работает от лица менеджера лофт-студии «Луна» — пространства для фото- и видеосъёмок, мероприятий, мастер-классов и частных встреч.

В диалоге он:

- уточняет потребность клиента: формат, дата, число людей, бюджет;
- предлагает подходящий формат аренды или съёмки;
- отвечает на вопросы о студии, залах, оборудовании и условиях;
- помогает оставить заявку или связаться с администратором;
- помнит последние 10 сообщений в каждом чате;
- по запросу генерирует и редактирует изображения (мудборды, референсы интерьера).

Стиль общения: дружелюбный, профессиональный, без давления. Ответы на русском, кратко и без markdown-разметки.

## Возможности

| Команда / запрос | Действие |
| --- | --- |
| `/start` | Приветствие и сброс истории диалога |
| `/help` | Краткая справка |
| `/clear` | Очистить контекст разговора |
| `/image описание` | Сгенерировать изображение |
| `нарисуй …` / `сгенерируй картинку …` | То же, без команды |
| `/edit описание` (ответом на фото) | Отредактировать изображение |

Если клиент просит картинку обычным текстом, бот подскажет `/image`. Если не хватает точных данных (цены, расписание), он честно уточняет контакты или предлагает связаться с администратором.

## Архитектура

```
Telegram  →  main.py  →  GigaChat (текст)
                      →  ProxyAPI  (картинки)
```

- `main.py` — Telegram-бот на [pyTelegramBotAPI](https://github.com/eternnoir/pyTelegramBotAPI): команды, история чатов, маршрутизация текста и изображений.
- `gigachat_client.py` — OAuth и chat completions GigaChat API.
- `proxyapi_client.py` — генерация и редактирование картинок через ProxyAPI.

История диалогов хранится в памяти процесса (до 10 сообщений на чат) и сбрасывается при перезапуске бота.

## Требования

- Python 3.10+
- Токен Telegram-бота от [@BotFather](https://t.me/BotFather)
- Ключ [GigaChat](https://developers.sber.ru/docs/ru/gigachat/api/overview) (Authorization key или Client ID + Client Secret)
- Ключ [ProxyAPI](https://proxyapi.ru/) — только если нужна генерация изображений

## Установка

```bash
git clone <url-репозитория>
cd Телеграм_бот_Cursor

python3 -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate

pip install -r requirements.txt
cp .env.example .env
```

Заполните `.env` своими ключами. Файл `.env` в Git не попадает.

## Переменные окружения

Скопируйте `.env.example` в `.env` и подставьте значения:

| Переменная | Обязательно | Описание |
| --- | --- | --- |
| `BOT_TOKEN` | да | Токен Telegram-бота |
| `GIGACHAT_AUTH_KEY` | да* | Готовый Authorization key GigaChat |
| `GIGACHAT_CLIENT_ID` / `GIGACHAT_CLIENT_SECRET` | да* | Альтернатива ключу: пара из кабинета Sber |
| `GIGACHAT_MODEL` | нет | Модель, по умолчанию `GigaChat-2` |
| `PROXY_API` | нет | Ключ ProxyAPI для картинок |
| `PROXY_API_BASE_URL` | нет | Базовый URL, по умолчанию `https://api.proxyapi.ru/openai/v1` |
| `IMAGE_MODEL` | нет | Модель картинок, по умолчанию `gpt-image-2` |

\* Нужен либо `GIGACHAT_AUTH_KEY`, либо пара `CLIENT_ID` + `CLIENT_SECRET`.

## Запуск

```bash
source .venv/bin/activate
python main.py
```

Бот работает через long polling. Оставьте процесс запущенным и напишите боту в Telegram: `/start`.
